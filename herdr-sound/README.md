# Ambient Sound for Herdr

Quiet audio cues for coding agents in [Herdr](https://herdr.dev/docs/plugins/): a low pulse while any agent is working, a tiny tink when Claude Code or Codex starts a tool call, and a three-note completion chime. The sounds are synthesized locally and played with macOS `afplay`. No Python packages or network service are needed.

The included WAV files were generated by [`sound.py`](sound.py); no third-party audio samples are used.

Requires macOS, Python 3, and Herdr 0.8 or newer.

## Install from GitHub

```sh
herdr plugin install programmarchy/herdr-plugins/herdr-sound
herdr plugin action invoke programmarchy.ambient-sound.configure
```

The first command installs the plugin from its public repository. The second sets up the Claude Code and Codex tool hooks and your local notification preferences. Existing agent sessions need a restart to load new hooks. Codex may require reviewing and trusting the new hook in `/hooks`.

Update a GitHub installation with `herdr plugin install programmarchy/herdr-plugins/herdr-sound`. The tool hooks call the plugin by ID, so updates do not need to rewrite their command paths.

## Install from a local checkout

From this directory:

```sh
./install-ambient-sound
```

This links the local plugin and configures it in one command. Setup adds asynchronous `PreToolUse` hooks to your user-level Claude Code and Codex settings. It disables Herdr's built-in background sound so completion does not chime twice, and switches Herdr's desktop notifications off. Use `--keep-native-sound` or `--keep-desktop-notifications` to retain either one. The setup script preserves other settings, backs up any settings file it changes, and is safe to run again.

Preview the sounds with `python3 sound.py preview`, or use the Herdr action `Preview sounds`.

## Adjust or mute

Control all three sounds from any terminal:

```sh
herdr plugin action invoke programmarchy.ambient-sound.mute
herdr plugin action invoke programmarchy.ambient-sound.unmute
herdr plugin action invoke programmarchy.ambient-sound.toggle
```

The change takes effect on the next cue, including in agents already running. Each command requests a silent top-right Herdr banner confirming the new state. To see the banner, set `[ui.toast] delivery = "herdr"` in `~/.config/herdr/config.toml`; Herdr's other agent notifications will then use in-app toasts too. Herdr actions have fixed commands, so the plugin declares one action for each choice. You can bind `programmarchy.ambient-sound.toggle` to a Herdr `plugin_action` keybinding if you want a keyboard shortcut.

Create `~/.config/herdr/ambient-sound.json` as needed:

```json
{
  "enabled": true,
  "volume": 0.35,
  "pulse": true,
  "tool": true,
  "done": true,
  "pulse_interval": 2.4,
  "tool_cooldown": 0.18
}
```

`volume` is from 0 to 1. Set `enabled` to `false` to mute immediately. The three sounds can be switched off separately. The interval and cooldown are in seconds. You can also point `HERDR_SOUND_CONFIG` to a different JSON file.

## How it works

Herdr's `pane.agent_status_changed` event starts a short-lived watcher when agent activity changes. It reads current agent states and runs a single pulse across all working agents, so multiple agents do not stack pulses. It plays the completion chime after an agent it saw working becomes idle or done. It exits after two quiet seconds. There is no long-running service.

Herdr does not expose each tool call as a plugin event. The `PreToolUse` hooks provide that signal directly from Claude Code and Codex. The hook command checks `HERDR_ENV=1`, so the tink plays only inside Herdr, and it coalesces tool calls that arrive close together. These hooks do not inspect or change tool arguments, permissions, or results.

Agent status is Herdr's own detection. If an agent is not recognized, or a very short turn begins and ends before Herdr reports it as working, its pulse/chime may not play. The tool cue remains available whenever the agent hook fires.

## Uninstall

For a local checkout, run:

```sh
./uninstall-ambient-sound
```

For a GitHub installation, run:

```sh
herdr plugin action invoke programmarchy.ambient-sound.uninstall
```

This unlinks the plugin, removes only its Claude Code and Codex hook entries, and restores Herdr's prior native sound and desktop notification settings if those sections have not been edited since installation. It leaves other hooks and settings in place. Restart agent sessions to unload their old hooks. The setup backups are available if you need to restore a file manually.
